# Wortweise – Englisch lernen

Eine minimalistische Karteikarten-Lernumgebung mit **159 Englisch–Deutsch-Vokabelpaaren in fünf Units**.

## Funktionen

- Karteikarten-, Schreib- und Zuordnungsmodus
- Lernrichtung Englisch → Deutsch, Deutsch → Englisch oder gemischt
- Zufällige Reihenfolge und Wiederholung unbekannter Karten
- Eigene Stapel und Vokabeln verwalten
- JSON-/CSV-Import und -Export
- Heller und dunkler Modus

Im Modus „Wörter zuordnen“ werden bis zu sechs Wortpaare gleichzeitig angezeigt. Wähle jeweils ein Wort und seine Übersetzung in der anderen Spalte. Falsche Zuordnungen markieren beide beteiligten Vokabeln zum weiteren Üben; sie lassen sich am Rundenende erneut lernen. Die Ergebnisanzeige zählt Paare, die ohne Fehler zugeordnet wurden.

## Nutzung

Die HTML-Datei herunterladen und im Browser öffnen – sie funktioniert ohne Installation und vollständig offline.

Für die Veröffentlichung über **GitHub Pages** die Datei als `index.html` im Repository ablegen und GitHub Pages aktivieren. Anschließend lässt sich die Lernumgebung über den veröffentlichten Link öffnen.

## Lernstand und Speicherung

Vokabeln, Einstellungen und Lernstände werden automatisch lokal im Browser gespeichert. Es gibt keine Anmeldung, keine geräteübergreifende Synchronisierung und keine Übertragung der Lernstände an die Lehrperson.

Zum Weiterlernen dasselbe Gerät und Browserprofil verwenden. Bei gemeinsam genutzten Browserprofilen wird auch der Lernstand geteilt. Gelöschte Browserdaten können zum Verlust der gespeicherten Daten führen.

**Tipp:** Regelmäßig über „JSON exportieren“ eine Sicherung erstellen.

## Technik

Eine einzelne HTML-Datei mit eingebettetem CSS und JavaScript – ohne externe Abhängigkeiten.
